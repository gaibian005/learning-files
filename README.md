# 学习文件

**[打开学习文件](https://gaibian005.github.io/learning-files/)**

用思维导图和案例一起学习商品流通、跨境交易、创业公司经营和组织设计。网站包含七章、十一张 SVG 和团队讨论题。公开资料、历史披露与教学假设标注在对应章节。

## 本地阅读

下载并解压后双击 `index.html`，即可打开目录和各章。思维导图的原文件放在 `assets/diagrams/`。

## 更新网站

章节在 `lessons/`，公共样式和图解查看脚本在 `assets/`。GitHub Pages 从 `main` 根目录发布。
